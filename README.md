# Fishing Depth Map

A free web map for finding fishing spots: depth contours, NOAA chart soundings, waterways, launches, and recently stocked lakes.

**Live:** https://jayceeninefive-star.github.io/fishing-map/

Data: Esri basemaps, NOAA charts & NCEI bathymetry, GEBCO, WDFW (lake contours, access sites, stocking via data.wa.gov), USGS NHD, OpenSeaMap, OpenStreetMap (Overpass, Nominatim).

**Not for navigation.** Depths are approximate and some surveys are old.
